# riblt docs

This directory contains the Fumadocs site for the `riblt` workspace.

Run the docs locally:

```bash
pnpm dev
```

Open http://localhost:3000 with your browser to see the result.

## Content

- `content/docs/index.mdx`: docs landing page
- `content/docs/riblt.mdx`: algorithm/package documentation
- `content/docs/orp.mdx`: ORP package documentation

## Useful Commands

```bash
pnpm dev
pnpm build
pnpm types:check
```
