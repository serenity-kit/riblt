This workspace is split into three layers:

- `riblt`: a low-level TypeScript implementation of Rateless Invertible Bloom Lookup Tables.
- `set-sync`: a JSON-first client/server protocol that uses `riblt` frames to reconcile two sets.
- `orp`: a document-scoped operation reconciliation protocol for opaque operations.

Use `riblt` directly if you need raw sketch generation and merge/decode control. Use `set-sync` if you want a higher-level session workflow between a client and server. Use `orp` if you need document inventory plus per-document operation repair.

## Typical Flow

1. Each side starts with a local set of string identifiers.
2. `riblt` turns that set into coded symbols that can be streamed incrementally.
3. `set-sync` wraps those coded symbols in session messages like `hello`, `sync`, and `sync-response`.
4. `orp` applies the same reconciliation primitive to document inventories and then to operation ids for differing documents.
5. Both sides keep exchanging frames until the diff can be decoded.
