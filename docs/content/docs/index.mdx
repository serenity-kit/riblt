This workspace is split into two layers:

- `riblt`: a low-level TypeScript implementation of Rateless Invertible Bloom Lookup Tables.
- `orp`: a document-scoped operation reconciliation protocol for opaque operations.

Use `riblt` directly if you need raw sketch generation and merge/decode control. Use `orp` if you need document inventory plus per-document operation repair.

## Typical Flow

1. Each side starts with a local set of string identifiers.
2. `riblt` turns that set into coded symbols that can be streamed incrementally.
3. `orp` applies the reconciliation primitive to document inventories and then to operation ids for differing documents.
4. Both sides keep exchanging frames until the diff can be decoded.
